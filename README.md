## 🚀 Featured Projects

### ⚡ SmartHire — AI Resume Screening & ATS Scoring Portal
> **Flagship Project** | Full-Stack · AI Integration · Production-Grade

An end-to-end AI-powered recruitment portal that automates resume screening and candidate ranking.

**What it does:**
- 📄 Candidates upload PDF resumes → Apache PDFBox extracts text → OpenAI GPT-3.5 analyses and returns ATS score (0–100) with strengths, weaknesses, and suggestions
- 🎯 AI calculates job-fit match score when candidates apply — admin sees all applicants ranked by match %
- 📧 Automated email notifications for selection/rejection with custom feedback
- 🌐 External job board where admin manages third-party job opportunities with apply links
- 🔐 JWT authentication + BCrypt password hashing + OTP mobile verification

**Technical highlights:**
- 20+ REST API endpoints across 4 Spring Boot controllers
- 7 normalised MySQL tables with foreign key relationships
- Rule-based fallback scoring engine — works 100% without OpenAI API key
- Exponential backoff retry logic for API resilience
- 3-tier architecture: React.js ↔ Spring Boot ↔ MySQL
